# OmniGuard AI

### 🛡️ Student-Led Cybersecurity Vulnerability & Automated Threat Log Analyzer

---

## 📋 Domain
Cybersecurity Operations, Applied Network Defense, and Automated Log Analytics.

---

## 🔍 Problem Statement
Small-scale digital portals, localized web applications, and educational institutional systems are constantly exposed to cyber threats such as brute-force login attempts and automated credential abuse. Traditional enterprise-grade Security Information and Event Management (SIEM) systems are highly complex, expensive, and require expert-level administration. There is a critical need for a lightweight, accessible tool that automatically tracks system logs, highlights common security anomalies using simple Python scripts, and leverages free AI APIs to instantly translate complex technical alerts into actionable, human-readable security reports.
